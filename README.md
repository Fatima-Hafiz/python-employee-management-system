# Python Employee Management System

## Project Overview

This project is a Python-based employee management system developed as part of my university coursework at Gulf College, Oman.

## Technologies Used

* Python
* Text files for data storage

## Project Files

* `Fatima (2).py` — Main Python program.
* `employee_record.txt` — Employee records.
* `employee_dept_role.txt` — Employee departments and roles.
* `employee_set_salary.txt` — Employee salary data.

## Learning Objectives

This project helped me practise Python programming and working with text files as part of an academic assignment.
